Installation Guide

Getting Auto-Crypter up and running

Everything you need to install TB Auto-Crypter and get your display set up correctly, from download to your first automated run.

What you'll need 1. Download 2. Install the folder 3. First launch 4. Set your display & zoom 5. Configure the app 6. Run it Need help?

What you'll need

  • Windows 10 or Windows 11.
  • Google Chrome installed, with you logged into the Total Battle account you want to automate.
  • A screen resolution of 1024×768, 1366×768, 1680×1050, 1760×990, or 1920×1080. Need something else? Email support@ccc-hq.com.
  • About 10 minutes, before your next crypting session.
Why the display settings matter: Auto-Crypter finds buttons and crypts by their exact position on screen. Step 4 below walks through the handful of settings that need to stay fixed so it always clicks in the right place.
1

Download Auto-Crypter

Grab the latest version below. It comes as a single .zip file.

Download v0.0.7
2

Unzip and install the folder

Auto-Crypter is distributed as a folder, not a single file — the .exe depends on other files that ship alongside it.

  1. Unzip the download.
  2. Copy the entire TBAutoCrypt folder to where you want to run it from — your Desktop or a dedicated Programs folder both work well.
  3. Don't move or copy just TBAutoCrypt.exe on its own — it won't launch without the rest of the folder.
3

First launch

  1. Open the TBAutoCrypt folder and double-click TBAutoCrypt.exe.
  2. Sign in with the Google account tied to your Total Battle play, and accept the access prompt Auto-Crypter shows you.
  3. Once that's done, the main Auto-Crypter window opens and you're ready for setup.
4

Set your display & zoom

Five settings need to match exactly, every time you run Auto-Crypter — not just today. Go through each one now:

Screen resolution — one of the supported sizes

Right-click your desktop → Display settings → set Display resolution to 1024×768, 1366×768, 1680×1050, 1760×990, or 1920×1080.

Windows display scale — 100%

Same Display settings page, under Scale & layout → set Scale to 100%. This is often set higher by default on laptop screens, so check it even if you never touched it.

Chrome browser zoom — 100%

In Chrome, press Ctrl+0 to reset zoom to 100% on the Total Battle tab. Chrome remembers zoom per site, so if you'd zoomed in before, reset it now.

Chrome's toolbar & bookmarks bar — hidden

Only the tab title and address bar should be visible above the page. Press Ctrl+Shift+B to hide the bookmarks bar, and clear any other toolbars from Chrome's toolbar area.

Total Battle's in-game map zoom — 125%

This one's inside the game, not Chrome or Windows. On the world map, use Total Battle's own zoom control to set it to 125%, and leave it there.

Don't mix these up: Chrome's browser zoom (100%) and Total Battle's in-game map zoom (125%) are two different settings. Auto-Crypter needs both set correctly at the same time.
5

Configure Auto-Crypter

Back in the app, a few quick choices before your first run:

  • Select your Total Battle window — so Auto-Crypter knows which browser window to watch.
  • Choose your captains — up to three per run.
  • Set your crypt filters — exclude any crypt types you don't want it to run (this will slow things down a little, so only exclude what you need to).
  • Optional: set a run limit — cap it by time or by number of marches, or leave it unlimited.
6

Run it

Open Total Battle to the watchtower or crypt list, then:

  • Click Start in the app, or press F9, to begin.
  • Press Ctrl+Q any time to stop immediately.
  • Keep an eye on it while it runs, and check the Logs area in the app if anything looks off.

Need a hand?

Stuck on a step, or running a resolution that isn't listed above? Email support@ccc-hq.com and we'll help you sort it out.
