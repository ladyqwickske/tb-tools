Installation Guide

Getting TB-Tools up and running

One download gives you both Auto-Crypter and the Battle Calculator. Here's everything you need, from download to your first automated run.

What you'll need

  • Windows 10 or Windows 11.
  • Google Chrome installed.
  • Total Battle set to English — Auto-Crypter recognises the English game screens only.
  • In Chrome mode: any screen resolution and any Windows scaling. In Desktop mode: one of the supported resolutions (see step 4).
  • About 10 minutes, before your next crypting session.
New in 1.0 — Chrome mode: Auto-Crypter can now control the game in a Chrome window of its own, so it runs in the background while you use your PC, at any screen resolution. Step 4 explains how to pick between Chrome mode and the classic Desktop mode.
1

Download TB-Tools

Grab the latest version below. It comes as a single .zip file and contains both Auto-Crypter and the Battle Calculator — there's nothing separate to download for either tool. Which tools you can use depends on your subscription or trial.

Download TB-Tools v1.0.1
2

Unzip and install the folder

TB-Tools is distributed as a folder, not a single file — the .exe depends on other files that ship alongside it.

  1. Unzip the download.
  2. Copy the entire TB-Tools folder to where you want to run it from — your Desktop or a dedicated Programs folder both work well.
  3. Don't move or copy just TB-Tools.exe on its own — it won't launch without the rest of the folder.
  4. Updating from an older version? Replace the old TB-Tools folder with the new one. Your settings and Chrome sign-ins are kept in your own user folder, so they stay.
3

First launch

  1. Open the TB-Tools folder and double-click TB-Tools.exe.
  2. Sign in with the Google account tied to your Total Battle play, and accept the access prompt TB-Tools shows you.
  3. Once that's done, the main TB-Tools window opens and you're ready for setup.
  4. Want the app in another language? Click the globe button (🌐) at the top right — 10 languages are available. The new language applies after a restart.
4

Choose a mode

Auto-Crypter can control the game in two ways. Switch in the General tab → Game control with the tick box “Control the game through Chrome (can run in the background)”. Ticked = Chrome mode, not ticked = Desktop mode. A new install starts in Desktop mode.

Chrome mode is the easiest choice for most players: your mouse and keyboard stay free, the game window may be covered or hidden, any screen resolution and Windows scaling works, and your own Chrome is left untouched. You can also keep a separate Login for each Total Battle account.

Chrome mode — runs in the background

  1. Tick “Control the game through Chrome (can run in the background)”.
  2. Click Open game in Chrome. A separate Chrome window opens with Total Battle — your own Chrome, bookmarks and passwords are not used.
  3. Sign in to Total Battle in that window. You only do this once per Login; the sign-in is remembered.
  4. Got more than one Total Battle account? Use Add… next to Login to give each one its own window and sign-in, and pick the right one before you press Start.

Two settings still matter in Chrome mode:

Chrome page zoom — 100%

In the game window TB-Tools opened, press Ctrl+0 to make sure the page isn't zoomed. The game page itself is always 1920×1080; on a smaller screen it's simply shown scaled down.

Total Battle's in-game map zoom — 125%

This one's inside the game. On the world map, use Total Battle's own zoom control to set it to 125%, and leave it there.

Handy options under Game control, all on by default: Full screen (the game without tabs and address bar), Hide while running (the game window moves out of sight during a run and comes back when it stops) and Check before START (shows you a picture of the game first, so you can check you're signed in and the right crypts are ticked).

During a run: don't minimise the game window (the game slows to a crawl — covering it or “Hide while running” is fine), and don't close the game window or TB-Tools.

Desktop mode — uses your real mouse

Auto-Crypter looks at your screen and moves your mouse like a player would, so you can't use the PC during a run. These settings need to stay fixed every time:

Screen resolution — one of the supported sizes

Right-click your desktop → Display settings → set Display resolution to 1024×768, 1366×768, 1600×900, 1680×1050, 1760×990, 1920×1080 or 1920×1200. Need something else? Use Chrome mode, or email support@ccc-hq.com.

Windows display scale — 100%

Same Display settings page, under Scale & layout → set Scale to 100%. This is often set higher by default on laptop screens, so check it even if you never touched it.

Chrome browser zoom — 100%

In Chrome, press Ctrl+0 to reset zoom to 100% on the Total Battle tab. Chrome remembers zoom per site, so if you'd zoomed in before, reset it now.

Chrome's toolbar & bookmarks bar — hidden

Only the tab title and address bar should be visible above the page. Press Ctrl+Shift+B to hide the bookmarks bar, and clear any other toolbars from Chrome's toolbar area.

Total Battle's in-game map zoom — 125%

On the world map, use Total Battle's own zoom control to set it to 125%, and leave it there.

Game window — maximised on the main monitor

Keep it visible, uncovered and in front during a run — don't move or minimise it.

Don't mix these up: Chrome's browser zoom (100%) and Total Battle's in-game map zoom (125%) are two different settings. Auto-Crypter needs both set correctly at the same time, in either mode.
5

Configure Auto-Crypter

Back in the app, a few quick choices before your first run:

  • Choose your captains — up to three per run. With three, you can also send two of them to the same crypt.
  • Optional: use speed-ups — each march gets a speed-up, and marches with more than 20 seconds left get another one while you wait.
  • Set your crypt filters — exclude any crypt types you don't want it to run (this will slow things down a little, so only exclude what you need to).
  • Optional: set a run limit — cap it by time or by number of marches, or leave it unlimited.
6

Run it

In the game (in Chrome mode: the window TB-Tools opened), go to your city or the world map, and in the Watchtower tick only the crypts you want. Auto-Crypter opens the Watchtower's crypt list by itself and starts searching where you left the list — so if you scroll it down to leave the nearest crypts for clanmates, it respects that and only looks higher up when crypts get scarce. Then:

  • Click Start in the app, or press F9, to begin. In Chrome mode, confirm the picture of the game and carry on using your PC.
  • Press Ctrl+Q any time to stop immediately.
  • Keep an eye on it now and then, and check the Logs area in the app if anything looks off. It stops by itself when a limit is reached, you run out of Tar or crypt keys, or the game page stops responding.

Need a hand?

Stuck on a step, or need Desktop mode at a resolution that isn't listed above? Email support@ccc-hq.com and we'll help you sort it out.
